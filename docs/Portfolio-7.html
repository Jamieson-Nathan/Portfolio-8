Portfolio 7: Next Steps

My thesis project was a loose replication of a project that look at self-other agreement in a Sri Lankan sample of trauma surviviors. One big difference was the scale used, and the posttraumatic growth inventory (PTGI) used in the previous study is multidimensional. What this allows is a deeper dive into the level of agreement by being able to unpack ‘normative’ and ‘distinctive’ elements of agreement at the domain-level. This allows a much more confident interpretation of any observed agreement, by being able to say that pairs don’t all agree in broad normative way, and that the agreement is distinctive and unique to each pair. Fortunately, the previous study uploaded all their data and R-Script to an online repository. So, the purpose of this study is to try and replicate their analysis, which will be something I want to do it in future projects - perhaps even one this semester I am looking at with relationship satisfaction among couples. Profile.cjr <- function(x.set, y.set, nomiss = 0.8, distinct = TRUE, trim = TRUE) {
  valids <- apply(cbind(x.set, y.set), 1, function(z) {
    valid.pairs(z[1:ncol(x.set)], z[-(1:ncol(x.set))])$Pct
  })

  mat <- suppressWarnings(cor(t(x.set), t(y.set), use = "pair"))
  if (trim) {
    mat[mat == 1]  <- 0.9999999
    mat[mat == -1] <- -0.9999999
  }
  overall.r <- diag(mat)
  overall.r[valids < nomiss] <- NA

  baseline <- mean(psych::fisherz(mat[upper.tri(mat)]), na.rm = TRUE)

  x.Norm <- colMeans(x.set, na.rm = TRUE)
  y.Norm <- colMeans(y.set, na.rm = TRUE)
  x.dist <- multicon::temp.resid(x.Norm, x.set, nomiss = nomiss)
  y.dist <- multicon::temp.resid(y.Norm, y.set, nomiss = nomiss)
  mat2 <- suppressWarnings(cor(t(x.dist), t(y.dist), use = "pair"))
  if (trim) {
    mat2[mat2 == 1]  <- 0.9999999
    mat2[mat2 == -1] <- -0.9999999
  }
  dist.r <- diag(mat2)
  dist.r[valids < nomiss] <- NA

  overall.test <- t.test(psych::fisherz(overall.r), mu = baseline)
  dist.test    <- t.test(psych::fisherz(dist.r),    mu = 0)

  tests <- data.frame(
    Agreement = c(
      N        = sum(!is.na(overall.r)),
      Mean     = psych::fisherz2r(mean(psych::fisherz(overall.r), na.rm = TRUE)),
      Baseline = psych::fisherz2r(baseline),
      t        = overall.test$statistic,
      p.value  = overall.test$p.value
    ),
    Distinctive = c(
      N        = sum(!is.na(dist.r)),
      Mean     = psych::fisherz2r(mean(psych::fisherz(dist.r), na.rm = TRUE)),
      Baseline = 0,
      t        = dist.test$statistic,
      p.value  = dist.test$p.value
    )
  )

  list(
    Agreement = data.frame(Overall = overall.r, Distinctive = dist.r),
    Tests     = round(tests, 3)
  )
}
